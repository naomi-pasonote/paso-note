# Paso Note（踊りじたく）

フラメンコのレッスン・課題・メモを整理し、日々の稽古を続けやすくするための個人用Webアプリです。

## 主な機能

- レッスン内容の記録
- 課題の整理
- ヌメロごとの管理
- 全体メモ
- スマートフォンからも利用可能
- PWA対応

## デモ

https://naomi-pasonote.github.io/paso-note/

## 制作について

日々のフラメンコレッスンで、複数のヌメロや課題を一か所で確認できるようにすることを目的として制作しました。実際に自分で使用しながら、見やすさと使いやすさを調整しています。

## 技術

HTML / CSS / JavaScript / Firebase

## バージョン
